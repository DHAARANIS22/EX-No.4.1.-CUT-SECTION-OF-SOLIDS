# EX No.4.1. CUT SECTION OF SOLIDS
## DATE:04-11-2026

## AIM
To create the solid model from given drawing and section the solid model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3.16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:


1. Open Fusion 360 and create a new design.
2. Select the XY plane and create a sketch.
   <img width="442" height="653" alt="Screenshot 2026-11-16 010723" src="https://github.com/user-attachments/assets/c22b0c8a-1d76-48fe-a35b-87091de6cdf7" />

4. Draw the base profile using Line, Circle and Arc tools.
   <img width="51" height="51" alt="Screenshot 2026-11-16 015231" src="https://github.com/user-attachments/assets/a0d5c267-335b-4057-a6f9-82abe5776e14" />
   <img width="52" height="46" alt="Screenshot 2026-11-16 014634" src="https://github.com/user-attachments/assets/aa9281fa-dbc0-48f1-a51c-f68f627f1d06" />
    <img width="192" height="82" alt="Screenshot 2026-11-16 020954" src="https://github.com/user-attachments/assets/8e54535f-5171-4271-a473-a6a5d1534c02" />


6. Apply the given dimensions and constraints.
7. Use Extrude to create the base.
   <img width="305" height="341" alt="Screenshot 2026-11-16 021239" src="https://github.com/user-attachments/assets/38d67eac-efdc-4f9a-a876-a5a61e393737" />

9. Create the central cylindrical boss of Ø50 mm.
10. Create a Ø20 mm central hole with Ø30 mm counterbore of 6 mm depth.
11. Create two Ø12 mm holes at the specified positions.
12. Use Extrude Cut to create the required holes and counterbore.
13. Complete the model as per the given sectional drawing and save it.
